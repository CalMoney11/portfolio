Art Buddy, AI critique for artists

Art students wait days for peer feedback. Art Buddy gives it in seconds: upload a piece and get a critique of its composition, color and technique. Now I'm turning it into a place where artists post work, follow each other, and talk about it.

How it came together

Next.js, OpenAI Vision API, Clerk, Google Cloud Functions, GitHub, Figma, VS Code

The first version was a ChatGPT embed hosted on GitHub Pages, with a Google Cloud Functions backend that handled image uploads, the API calls, and cleanup afterward. Once I wanted accounts and a social feed, I replanned the whole thing and moved to Next.js with Clerk for sign-in and billing.

  1. Figure out the API flow

    First I had to understand how an image gets from the browser to OpenAI and back.

  2. Ship a simple page

    I put that flow on a basic page hosted with GitHub Pages so I could test it with real artwork.

  3. Explore a look

    Next I worked out the visual style I wanted.

  4. Prototype the social side in Figma

    I realized I wanted more than a critique tool. Art students should be able to stay connected and give each other feedback too.

  5. Replan it as a flowchart

    In Eraser.io I mapped out every piece the social version needs and how each one would work.

  6. Choose the stack

    The flowchart made the stack choice straightforward.

  7. Sign-in

    Accounts work, through Clerk.

  8. Landing page

    The front door for new users.

  9. Store user data

    A way to save and use each user's work and data.
